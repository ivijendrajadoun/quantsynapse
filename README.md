# QuantSynapse Single-Page Website

This is a single-page static website. Navigation uses section anchors rather than separate HTML pages.

## Deploy to Cloudflare Pages
- Upload/push the contents of this folder to the connected GitHub repository.
- Build command: leave blank.
- Build output directory: `.` / repository root.
- Keep `assets/styles.css` and `assets/app.js` beside `index.html`.

## Before publishing
- Replace `CONTACT_EMAIL_HERE` in the contact/privacy/terms sections.
- Review legal text for your actual operation.
- Validate calculator formulas and pip-value assumptions.
- Review privacy and consent requirements before enabling analytics or ads.
